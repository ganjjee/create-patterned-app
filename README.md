# create-patterned-app

🛠 A CLI tool that scaffolds frontend project structures based on design patterns

## Getting Started

```bash
npx create-patterned-app my-app --pattern atomic --ts --react
```

## Features

• Supports Atomic, FSD, and more<br />
• TypeScript / JavaScript selectable<br />
• React / Vanilla optional<br />
• Pre-configured folder structure<br />
